You are upgrading the existing https://shotgunninjas.studio project into Shotgun Ninjas Virtual Studio v2.

Goal:
Transform the current fun browser-based DAW/music toy into a more advanced, realistic, polished browser DAW experience while preserving the existing working functionality, routes, branding, and deployment behavior. Do not delete working features unless replacing them with a better compatible version. Audit the current codebase first, then implement incrementally.

Primary outcome:
The app should feel like a compact browser DAW with a cyber-ninja studio aesthetic: realistic sounds, better sequencing, a real mixer, better transport controls, project save/load, export, visual feedback, and a more immersive UI.

Technical priorities:
1. Preserve the existing project structure where possible.
2. Use React/Vite conventions already present in the project.
3. Use Tone.js as the main music timing/audio framework if already installed; otherwise add it.
4. Add wavesurfer.js only where waveform display/editing is useful.
5. Use IndexedDB through a small storage helper for projects, samples, and user-created patterns.
6. Keep the app browser-only unless a backend already exists.
7. Do not add paid APIs or external cloud dependencies.
8. Keep all audio user-gesture requirements handled cleanly with a single “Enable Audio” state.
9. Make mobile/tablet responsive, but optimize first for desktop/laptop production use.
